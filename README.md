## 🚀 Featured Projects

### MYA — Multi-Agent AI Platform
`98,000+ users` · `2 countries (Germany, Poland)` · `AutoGen v0.4`
Architected a production multi-agent platform with a central orchestrator routing to **6 specialized agents**, ReAct reasoning, and OpenAI function-calling across **13+ tools spanning 5 enterprise systems** via MCP-style integration. Built a 4-layer NLP intent classification pipeline with precision/recall/F1 evaluation, real-time SSE streaming over async FastAPI, 11-step and 6-step stateful agent workflows, and async PostgreSQL (asyncpg + SQLAlchemy 2.0). Integrated ServiceNow OAuth2, Bosch SAP/SRM APIs, and a Vue 3 frontend with Azure Entra ID SSO.

### Team Copilot — Agentic HR Platform
`6,000+ HR users` · `LangGraph` · `10 agents (cross-regional)`
Designed an agentic orchestration system with a central router dispatching to 5 specialized agents (talent analysis, interview coaching, team design & more), extended with 5 additional agents from a cross-regional Chinese team using A2A-style agent-to-agent communication. Tool-augmented workflows via LangChain with embeddings-based skill lookup and Pydantic schema-safe structured outputs.

### Legal RAG Chatbot
`Hybrid Search` · `GPT-4V` · `Azure AI Search`
RAG chatbot combining keyword, semantic, and vector search with ada-002 embeddings and a semantic ranker for citation-grounded answers. Extended with GPT-4V multi-modal vision for scanned documents, access-controlled document vaults, and Azure Speech Services for voice Q&A.

### Makzyra AI — Multi-Agent Website Builder
`6-agent pipeline` · `Claude + GPT` · `Self-healing`
Multi-agent system spanning product intelligence, UI design, planning, code generation, testing, and auto-repair — using Playwright-based 22-test validation, SSE streaming, and self-healing code repair via prompt chaining.

### GenSQL — Natural Language to SQL Engine
Azure OpenAI function-calling engine that generates optimized multi-table JOINs from natural language, eliminating developer dependency for ad-hoc data requests.

### CAS Number Crawler
LangChain + Azure OpenAI pipeline using semantic chunking and web search to automate regulatory lookups — cut a 3+ hour manual process to under 10 minutes per batch.
